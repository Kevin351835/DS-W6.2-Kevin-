Output tersebut menampilkan hasil dari sebuah proses perulangan ( looping ) yang mencatat setiap putaran ( Turn ) secara berurutan, di mana sistem melakukan pengecekan status karakter yang menghasilkan pesan "Try Again" saat nilai angka di akhir masih lebih besar dari nol dan berubah menjadi "Get Out" ketika nilai tersebut mencapai angka nol.[alt text](image.png)
